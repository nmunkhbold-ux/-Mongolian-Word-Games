# Монгол үгийн тоглоомууд

Монгол хэл дээрх хоёр өдөр тутмын үгийн тоглоом.

- **Таавар** (`taavar.html`) — 5 үсэгтэй монгол үгийг 6 оролдлогоор таа.
- **Үгийн сүлбээ** (`sulbee.html`) — 16 үгийг нийтлэг шинжээр нь 4 бүлэгт хуваа. Өдрийн болон хязгааргүй горимтой.

Тоглох: https://nmunkhbold-ux.github.io/-mongolian-word-games/

Нэмэлт сан, сервер шаардлагагүй. Энгийн HTML файлууд тул ямар ч вэб сервер дээр ажиллана.
